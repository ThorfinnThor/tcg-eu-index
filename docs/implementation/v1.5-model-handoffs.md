# Methodology v1.5 Model Handoffs

This file records the agreed Luna/Sol division so model switches do not change the implementation contract.

Official OpenAI guidance positions Sol for complex professional reasoning and coding, and Luna for efficient, high-volume workloads. See <https://developers.openai.com/api/docs/guides/latest-model>. Each completed work package must end with an explicit next-model instruction.

## S1 — Sol: methodology contract

Status: complete.

Scope:

- EUR 10 singles and EUR 30 sealed thresholds
- uncapped all-eligible-variant membership
- no price-band quotas or concentration caps
- new number-free index codes and separate histories
- canonical `avg30` valuation with private `avg7` calibration

- private shadow and manual cutover boundaries
